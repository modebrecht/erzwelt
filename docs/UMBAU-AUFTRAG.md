# Refactor brief: patch layers → modules

Repo: modebrecht/erzwelt. Goal: refactor the patch layers into modules WITHOUT any
change in behaviour, text or visuals. Work autonomously, do not ask the user
questions; he only checks the result on his phone.

## Context
- erzwelt-core.html plus ~45 patch files loaded in the order of patches.json; many
  patches reassign global functions (name = function / wrappers), up to ~11 layers
  per function. index.html is generated by `node scripts/build-standalone.mjs`
  (never edit it by hand).
- Reference only (do NOT merge, outdated): docs/MODULE-KONZEPT.md and
  tests/vergleich/ from branch claude/module-umbau.
- Production (erzwelt.vercel.app) is used by students: main must always work.
- Tests: tests/unit/certificate.mjs and tests/e2e/*.mjs against
  `python3 -m http.server 4173`. intro-entdeckungen needs the offline build
  (`--offline`). Locally, a failing Google Fonts request is expected; CI on GitHub
  is authoritative.

## Workflow
1. Tag current main as `vor-umbau` and push the tag.
2. Create ONE branch `umbau` from main; all work happens there. Open a draft PR
   right away (Vercel builds a preview for every push).
3. Port the comparison harness (tests/vergleich/) to the current game (main menu,
   save slots, picture intro) and record a reference from main.
4. Write a script that lists all reassignments/wrappers per global function in
   patches.json order; commit it together with its output.
5. Modules in this order: quest, blatt, seiten, map & pins, einfuehrung, wissen,
   notifications & sound. For each one: merge all layers into one file, remove
   the old layers, update patches.json and README, build, comparison
   = 0 differences, all e2e green, push. If anything differs: stop and find the
   cause, never fix forward.
6. Move all visible texts into texte.de.js (key → text). No English yet.
7. When everything is green and the preview looks identical at phone size:
   merge the PR into main and delete the branch `umbau` (remotely and locally).
8. Final report to the user in German: short, what changed, the preview link,
   any open items.

## Rules
- No new features, no wording, design or balancing changes.
- Small commits, German commit messages that explain why.
- Feature freeze on main until the merge.
- Known suspicion to check along the way: «Tutorial abgeschlossen» feedback may
  be queued twice. Record it only, do not fix it in this refactor.
